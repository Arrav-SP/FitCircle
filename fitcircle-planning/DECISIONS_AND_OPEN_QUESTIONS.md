## 2. Proposed decisions

| # | Decision | Alternative | Why |
|---|---|---|---|
| P1 | The plan assumes 4–5 hours a day (85–110 hours) | Fewer hours with a smaller scope | The owner has not said how many hours a day are available. If fewer, the cut order in the blueprint applies |
| P2 | Friends connect through single-use invite links that expire in 7 days; no user search | Username search and friend requests | Simplest secure way to admit only intended people |
| P3 | Friend and streak changes are PostgreSQL functions; the app cannot write those tables | App writes with policies only | Transactions and locks; one place to test |
| P4 | Streaks count agreed weekdays, not every day | Daily streaks | Rest days are built in |
| P5 | A day is finalised at 03:00 the next morning; finalised days never change | No grace; unlimited recalculation | Allows a late-night log, stops backdating |
| P6 | A missed scheduled day resets the streak to 0; the longest streak is kept; no freezes | Streak freezes | Simplest |
| P7 | Streak configuration is fixed after acceptance and starts the next day | Editable | No renegotiation rules needed |
| P8 | One live streak per pair; two participants stored as two columns | A participants table | Exactly two people |
| P9 | Feed items are generated by the database with no free text | User-written posts | Nothing to moderate; notes cannot leak |
| P10 | Sharing is off by default, per workout | On by default | Privacy first |
| P11 | No push, no offline queue, no realtime, no edge functions in this phase | Build them now | Not needed for ten people; each returns with a named trigger in blueprint section 5 |
| P12 | No block, report, rate limit, age gate, consent record or data export in this phase | Build them now | Everyone is a known friend. Required before any public release |
| P13 | Development on the local Supabase stack; one free hosted project for the group | Two hosted projects | Keeps test data away from real data (see Q1) |
| P14 | One `metric_entries` table for water, steps and sleep | A table per metric | Same shape and rules |
| P15 | Weekly manual database dump, and one before each migration | No backups | The free tier has none [S25] |
| P16 | Four tabs: Home, Log, Streaks, Profile | Five tabs | Enough for this scope |

## 3. Open questions that block building

Only these. Each is answered on the day shown.

| # | Question | Why it blocks | How it is answered | Day |
|---|---|---|---|---|
| Q1 | Will Docker and the Supabase local stack run on the owner's Windows machine? | Needed for local development and for running the database tests | Install and start it on day 1. If it fails within two hours, use a second free hosted project for development and run tests there | 1 |
| Q2 | Which free static host, and does Google sign-in's redirect work on its subdomain? | The group needs a public link; sign-in is the only way in | Deploy a sign-in-only page on day 1–2. EAS Hosting is the first candidate [S4][S26] | 1–2 |
| Q3 | Can a database function delete the user's sign-in record on hosted Supabase? | Decides whether account deletion needs an edge function | Try it on day 14. Fallback: one small edge function | 14 |
| Q4 | How many hours a day can the owner give? | Decides whether the full scope or a reduced one is built | The owner answers before step 1 starts | Before 1 |

## 5. Risks

| # | Risk | Likelihood | Impact | Handling |
|---|---|---|---|---|
| R1 | An access-rule mistake exposes private data | Medium | High | Default deny; tests for allow and deny; line-by-line read in step 8 |
| R2 | The 20 days run out | Medium–high | Medium | Checkpoints at days 5, 10, 15; fixed cut order |
| R3 | The streak engine is wrong | Medium | High | 17 database tests written before the screens |
| R4 | Google sign-in or hosting setup eats day 1–2 | Medium | Medium | Done first so the slip is visible |
| R5 | Data loss on the free tier | Low | High | P15 |
| R6 | No reminders weakens the streak habit | High | Medium | Accepted; push is first after the beta |
| R7 | Workouts are self-reported | High | Low among friends | Accepted |
